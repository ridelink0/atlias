## Changes and evidence gates

1. Close and audit the existing source7d48-call plan without retrying the failed quota row. Reconstruct request counts and distinguish first-request prefix costs, source discovery, edits, checks and polling. Retain all costs and unfavorable cases.
2. Run the independent1260 seeded behavioral probes on COPIES of completed model source. The original protected graders, reports and scores remain unchanged. Record every additional counterexample and every Atlias regression; finite tests are not universal output equivalence.
3. Prototype a default-off bounded native-job broker, rather than another tiny brief rewrite. Use the existing Codex/Claude Code subscription clients; preserve model/effort/user prompt and all Gev instructions. Test an explicit compact native instruction profile and an action packet that combines edits with functional/adversarial checks. The broker must enforce allowed paths, source hashes, concurrent-edit protection, hidden-grader isolation, destructive guards, bounded jobs and every-attempt accounting. Failures must be retained; no automatic identical retry. A bounded job profile is not general interactive feature parity.
4. Verify the compact profile with actual model-free clients for BOTH hosts before inference: generated versus delivered source, instruction preservation, packet schema, command serialization, output parsing, auth cleanup and adversarial path/secret/tamper cases. Native Codex's documented model_instructions_file can replace built-in instructions; a real delivery check must establish what user instructions remain. Claude's actual CLI flags must be checked, not assumed. No live user configuration changes or activation before this evidence.
5. Only after that implementation changes a measured prefix or removes specific model requests, predeclare a NEW matched study. Use unchanged contracts, full original output assertions, source hashes and all attempt costs. Include peak, raw input, output and total, not just cache discounts or metadata. Do not call the broker measured or integrated while it remains a prototype.
6. Add the independently pinned AA-Omniscience-Public600 factuality track with protected gold answers and a pinned external judge. Measure accuracy, hallucination rate, abstention and index together. A tool-assisted evidence track must have a different name/protocol: the publisher's test is closed-book. AA preparation and metric tests are not Atlias results. Count solver AND judging calls in Gev's cost accounting.

The [bounded-job packet/staging prototype](../tools/native-job/README.md) passed37 model-free packet/check controls and15 native-runner preparation/failure/accounting controls. Real native Codex against a localhost fixture delivered the full packet and replacement instructions; a separate Claude bare-mode fixture did too after an original non-bare startup timeout. This does not verify Claude subscription-mode delivery, generic feature parity, inference usage or a completed real model job. Actual native activation, cost reconciliation and matched comparison remain unfinished.
