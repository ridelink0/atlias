## Fix demonstrated causes before inference

The integrity gate previously let an unrelated unverified disclaimer suppress an affirmative test-success claim. It also let a recorded unknown check outcome or a pass preceding a later edit substantiate current success. Clause-local success detection now requires a recorded passing result after the latest edit. The check remains a conservative wording/evidence guard, not an oracle for arbitrary factual claims. Negated claims, questions, conditional statements and honest uncertainty stay allowed; actual supported success with uncertainty about another subject stays allowed. Both hosts use this gate.

The common startup rule now requests inspected evidence, localized uncertainty and useful supported answers without adding a long instruction block. No tools, permissions, stock native instructions or model capability are removed by this rule. Its effect on model quality remains unmeasured until a new pinned comparison closes.

AA native answering/judging previously checked percentages from a potentially stale CLI result without a fresh timestamp or explicit paid-credit-off proof. The adapter now requests refresh for Codex, requires a fresh snapshot and every quota window, and refuses enabled or unknown paid-credit state on either host. Claude's CLI cannot refresh its OAuth meter; stale readings therefore fail closed. This is an Atlias inference prerequisite fix, not a Usage Limits feature change. Real Claude inference remains unavailable until genuine fresh allowance evidence permits it.
