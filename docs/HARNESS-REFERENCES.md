The default-off `flags.taskContext` applies requirements-first packing to both Claude Code and Codex prompt hooks. It includes small whole files explicitly named in the prompt and static local JavaScript imports recognized by its bounded pattern matcher. Real paths are deduplicated; hidden, credential, external, binary and oversized files are excluded. A source group is rejected as a whole if a recognized prerequisite cannot fit. The rendered pack is capped at 10,000 characters and eight files, with omissions stated. Existing graph answers keep priority. This is Atlias's own implementation, not a general JavaScript/TypeScript parser or the reference's module engine. Native measured outcomes, exact source and limitations are recorded in the [task-context report](../evals/results/native-codex/codex-atlias-pack-2026-09-30/REPORT.md); they do not establish Claude-model savings or lower peak context.
